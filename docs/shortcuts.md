# Shortcuts

## On this page

- [Groups](#groups)
- [Photos](#photos)
- [Video](#video)

These work while a group is open. They do nothing while the cursor is in a text field.

Details also sit on [Review](review) and [Photos](photos).

## Groups

| Key | Action |
| --- | --- |
| `Left` | Previous group |
| `Right` | Next group |

## Photos

On a group that is only images:

| Key | Action |
| --- | --- |
| `1`–`9` | Show that item. `1` is the first. |
| `0` | Show the best item |
| `Enter` or `Space` | Show the filmstrip thumbnail that has focus |

Scroll to zoom, drag to pan, double-click or **Fit** to reset. Drag a thumbnail onto the photo for [difference mode](photos).

## Video

`Left` and `Right` change the group, unless the playback slider is focused.

| Key | Action |
| --- | --- |
| `Left` / `Right` | Step through the clip |
| `Home` / `End` | Start or end of the clip |

Stack, trash, ignore, merge, and extract are buttons. There is no key for them.
